{% if session.get('lang','ar') == 'en' %} 🟢 Top-up (Deposit) {% else %} 🟢 الشحن (الإيداع) {% endif %}

{% if session.get('lang','ar') == 'en' %}
  • Top-up is done automatically with USDT/BTC or manually with USDT after verifying the amount and the TxID.
  • The minimum top-up amount is $10.
  • Top-up details are always verified manually by the admin before the balance is added to your account.
{% else %}
  • الشحن سيكون أوتوماتيكيّاً USDT/BTC أو يدوياً عبر USDT بعد التحقق من المبلغ ورقم العملية (TxID).
  • أقل مبلغ للشحن هو 10 دولار ($10).
  • يتم التحقق من بيانات الشحن يدويًا من طرف الإدارة قبل إضافة الرصيد إلى حسابك.

{% if session.get('lang','ar') == 'en' %} 📤 Withdrawals & Fees {% else %} 📤 السحب والعمولات {% endif %}

{% if session.get('lang','ar') == 'en' %}
  • The minimum withdrawal amount is $35.
  • Withdrawal fees:
    • 1% for withdrawal amounts above $100.
    • 5% for withdrawal amounts below $100 from the withdrawable balance.
  • Currency conversion inside your balance has no platform fee, but the final result may vary due to market exchange rates.
{% else %}
  • أقل مبلغ للسحب هو 35 دولار ($35).
  • عمولة السحب:
    • 1٪ للمبالغ التي تتجاوز 100$.
    • 5٪ للمبالغ التي تقل عن 100$ من رصيد السحب.
  • عمليات التحويل بين العملات داخل رصيدك لا تُحتسب عليها عمولة من المنصة، ولكن قد تختلف نتيجة سعر الصرف حسب السوق.
{% endif %}
